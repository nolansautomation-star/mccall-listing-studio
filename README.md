# McCall Listing Studio

Public website for McCall Listing Studio, a listing marketing service based in Grand Rapids, Michigan.

Live site: https://nolansautomation-star.github.io/mccall-listing-studio/

Static site, no build step: `index.html`, `assets/styles.css`, `assets/main.js`, `assets/scene.js` (Three.js hero scene loaded from jsDelivr), `logo.svg`, `favicon.svg`. The 3D scene is skipped for visitors who prefer reduced motion or whose browser lacks WebGL; a static logo illustration shows instead.
